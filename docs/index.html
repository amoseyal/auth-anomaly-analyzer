Detection Methodology

Identifies failed authentication attempts originating from the same source IP address against multiple distinct accounts. A detection is generated when at least five unique accounts are targeted within a ten-minute window.

Analyst Interpretation

Failed authentication attempts against multiple accounts from a common source IP may indicate password spraying, in which an attacker attempts a small number of passwords across many accounts. Shared infrastructure or legitimate automated processes may produce similar activity. Review the source IP, targeted accounts, timing, and subsequent authentication outcomes to assess potential exposure.

Detection Methodology

Identifies a successful authentication following repeated failed attempts against the same account from the same source IP address. A detection is generated when a successful login follows at least five failures within the preceding ten minutes.

Analyst Interpretation

A successful authentication following repeated failures may indicate that a credential-guessing attempt succeeded. However, it may also represent a legitimate user entering the correct password after several mistakes. This pattern warrants closer examination of the successful session, including device information, geographic context, MFA results, and subsequent account activity where available. The detection alone does not establish account compromise.
